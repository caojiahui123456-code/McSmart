# Demo 演示指南

比赛 Demo 建议按以下三个场景展示，覆盖全部六项能力。

## 场景 1: 减脂党 — 营养分析驱动

**用户输入**: "我在减脂期，想要高蛋白低卡，预算 50 以内，帮我配个午餐"

**展示链路**: food_query → nutrition（并行查多候选）→ coupon → pricing → store_locator → recommend

**预期输出**: 2-3 套方案，标注每套热量/蛋白质与每日参考占比、可用优惠、总价、推荐门店。

## 场景 2: 预算党 — 优惠与价格驱动

**用户输入**: "帮我找最划算的吃法，30 块钱以内怎么组合最值"

**展示链路**: food_query → coupon（找最大折扣）→ pricing（多组合比价）→ recommend

**预期输出**: 组合比价表，突出"用券后省了 X 元"。

## 场景 3: 遛娃家庭 — 门店与场景驱动

**用户输入**: "带孩子出去玩，附近哪家麦当劳有适合小朋友的套餐"

**展示链路**: store_locator → food_query（儿童套餐）→ nutrition → coupon → pricing → recommend

**预期输出**: 附近门店列表 + 儿童套餐方案 + 家庭总价。
