# 架构说明 — McSmart 麦智点餐官

## 分层架构

```
┌─────────────────────────────────────────────┐
│  skill/        Skill 定义层（触发规则/编排知识）│
├─────────────────────────────────────────────┤
│  src/agent/    智能体层                       │
│    orchestrator  意图理解 + 任务编排           │
│    planner       工具调用计划（DAG）           │
├─────────────────────────────────────────────┤
│  src/services/ 业务层（六大能力，互相独立）     │
│    food_query / nutrition / coupon /         │
│    pricing / store_locator / recommend       │
├─────────────────────────────────────────────┤
│  src/mcp/      MCP 接入层（统一客户端封装）    │
├─────────────────────────────────────────────┤
│  麦当劳 MCP Server（官方提供）                │
└─────────────────────────────────────────────┘
```

## 设计原则

1. **Skill 与实现分离** — `skill/` 描述 Agent 行为，`src/` 承载工程实现
2. **业务层不碰传输** — services 只依赖 mcp 层接口，方便 mock 测试
3. **六大能力单一职责** — 每个服务一个模块，对应比赛要求的六项能力
4. **全链路可演示** — demo/ 保存场景脚本与截图，output/ 保存运行产出
