# 营养评级规则（健康模式 · goal → 约束表）

> 数据源: `list-nutrition-foods`（官方营养表，160 条餐品实测）
> 字段: 能量 kcal / 蛋白质 g / 脂肪 g / 碳水 g / 钠 mg / 钙 mg
> ⚠️ 官方数据**无"糖"字段** → 低糖目标以**碳水**为代理指标
>（含精制碳水与膳食纤维，阈值按单餐控糖需求放宽）

本表与 `src/services/recommend.py` 的 `GOAL_NUTRITION_RULES` 一致，
是 `filter_candidates`（单品硬过滤）与 `build_combos`（组合上限）的唯一依据。

## goal → 单餐约束

| Goal | 热量上限 kcal | 蛋白下限 g | 脂肪上限 g | 碳水上限 g(低糖代理) | 钠上限 mg | 典型场景 |
|------|-------------|-----------|-----------|--------------------|----------|---------|
| 减脂 FAT_LOSS | 600 | 20 | - | - | 800 | "减肥/减脂/轻食" |
| 增肌 MUSCLE_GAIN | 900 | 30 | - | - | - | "增肌/练后/高蛋白" |
| 儿童 KIDS | 500 | 10 | - | - | 600 | "孩子/儿童餐" |
| 低糖 LOW_SUGAR | 700 | - | - | 50 | - | "控糖/低糖/无糖" |
| 低脂 LOW_FAT | 700 | - | 15 | - | - | "低脂/少油/清淡" |
| 普通 NORMAL | 1200(兜底) | - | - | - | - | 无特殊目标 |

## 阈值设计依据（单餐口径，成人日参考值的 1/3 上下）

- **减脂**: 单餐 600kcal ≈ 每日 1800kcal 缺口饮食的三餐均摊；
  蛋白 ≥20g 保证饱腹与肌肉保留；钠 ≤800mg 控水肿
- **增肌**: 蛋白 ≥30g 达到单餐亮氨酸阈值的实际食物量；
  热量放宽到 900kcal 支持热量盈余
- **儿童**: 热量 ≤500kcal、钠 ≤600mg 按 4-8 岁儿童单餐参考；
  蛋白 ≥10g 保发育（低阈值避免误杀儿童餐）
- **低糖**: 碳水 ≤50g/餐 对应控糖饮食的单餐碳水配额
  （若官方未来提供糖字段，应改用 `max_sugar` 直接约束）
- **低脂**: 脂肪 ≤15g/餐 约为成人单餐脂肪参考上限的保守值

## 执行规则

1. **硬过滤**（单品层，`filter_candidates`）: 任一维度超标即剔除，不进候选池
2. **组合上限**（`build_combos`）: 组合合计的热量/碳水/脂肪/钠/预算估计
   不得超过上限；用户显式值（如"500卡以内"）优先于规则表
3. **排序**: 候选按蛋白密度（蛋白 g ÷ 100kcal）降序——单位热量营养回报最高
4. **评分**（`score_goal`）: 每条规则等权，达标 100 分，
   超标线性扣分（碳水 ×4/克、脂肪 ×8/克、钠 ×0.1/毫克）

## 实测校验样例（2026-10-10，北京中粮广场店）

- 低糖模式: "薄皮焦香V翅 + 鲜萃咖啡 + 浓缩咖啡" 218kcal / 碳水 8g ✅
- 低脂模式: "薄皮焦香V翅" 192kcal / 脂肪 11g（≤15g）✅
- 儿童模式: 钠 594mg 单品通过；V翅+麦乐鸡组合（钠 1016mg）被组合上限正确拒绝
