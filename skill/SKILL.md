# McSmart 麦智点餐官

## Skill 描述

用户以自然语言表达点餐目标（营养目标、预算、口味、位置），
本 Skill 编排麦当劳 MCP 工具完成：食品查询 → 营养分析 → 优惠发现 →
价格计算 → 门店推荐 → 智能点餐建议。

## 三种工作模式

| 模式 | 触发示例 | 流水线 |
|------|---------|--------|
| **健康模式**（五目标: 减脂/增肌/儿童/低糖/低脂） | "控糖，推荐个低糖晚餐" | 营养表交叉筛选（硬约束: 热量/蛋白/脂肪/碳水/钠）→ 组合生成 → 券后价试算 → 三维评分 |
| **省钱模式** | "今天吃麦当劳怎么最划算" | 我的券 → 门店券 → 活动 → 券×商品/组合试算 → 按节省比例排序 |
| **门店模式** | "附近哪里可以买" | query-nearby-stores → 距离/营业状态/推荐理由三要素卡片 |

## 使用方法（执行入口）

本 Skill 的执行体是项目根目录下的 Python CLI（五段流水线编排器）：

```bash
cd McSmart
python -m src.main "帮我推荐一个500卡以内，30元以内的麦当劳套餐"
```

Agent 收到用户自然语言后，将需求原样传给 CLI 并把输出渲染给用户。
前置条件：项目根目录 `.env` 已配置 `MCP_SERVER_URL` / `MCP_AUTH_TOKEN`
（模板见 `.env.example`），依赖见 `requirements.txt`。

## 能力边界

- 输入: 自然语言需求（如"减脂期，预算 40，附近有店吗"）
- 输出: 2-3 套结构化点餐方案（菜品 + 营养评级 + 优惠 + 总价 + 门店）
- 不做: 支付闭环、跨品牌比价
- 低糖说明: 官方营养数据无"糖"字段，以碳水为代理指标（见 references/nutrition-rules.md）
